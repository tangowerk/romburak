### Linux aarch64
- The managed RetroArch also runs on Linux aarch64 (e.g. NVIDIA DGX Spark). The buildbot has no stable build there, so Romburak installs the newest nightly plus the menu assets, and cores from the aarch64 nightlies. RetroArch needs SDL2 from the system (`libsdl2-2.0-0`); the deb now depends on it.

### Appearance
- New Omarchy theme: the Matte Black palette, monospace everywhere, flat square panels with a border that lights up like a focused Hyprland window. System → Appearance or `Ctrl K` → "Theme: Omarchy".

### Import
- Ambiguous matches pick the candidate the file's extension or folder points to.
- Planning over network shares (CIFS/SMB) is faster: no per-archive zip reads or folder checks (real library: ~25 s → ~10 s).

### Dashboard
- Loading hint and progress bar while the library loads.

### Fixes
- Resolving an ambiguous zip stores the ROM's hash, not the archive's, so the decision no longer comes back on every plan.
- Launchers next to a game found in a subfolder count as that game's data.
- Game folders without a database match list as one game, not as unknown files.
- Unknown files show their file name and sort last.

### Linux aarch64
- The managed RetroArch also runs on Linux aarch64 (e.g. NVIDIA DGX Spark). The buildbot has no stable build there, so Romburak installs the newest nightly plus the menu assets, and cores from the aarch64 nightlies. RetroArch needs SDL2 from the system (`libsdl2-2.0-0`); the deb now depends on it.

### RetroArch
- RetroArch settings moved from their own sidebar tab to System → RetroArch (they are settings). System now sits in the sidebar right below Rules. Shortcuts: Rules is now `Ctrl 4`, System `Ctrl 5`.
- Opt-in nightly channel: "Try nightly" next to the stable install (Settings → RetroArch) or `romburak ra install --version nightly`. Stable 1.22.2 stays the default; cores were already the newest nightlies.
- Shader picker: filter by category (top folder) with a short description of each category, and the number of passes per preset as a GPU-load hint.
- Shader previews: every preset shows a thumbnail, and pointing at one shows a large preview of the same test picture through that shader, whole screen next to a 1:1 detail (scanlines, masks). Previews are rendered once by us and loaded on demand.
- Shader history: when a preset was added to slang-shaders, last changed, and by whom. Sort the list by name, newest, recently changed or fewest passes; search also matches the author.
- Shader package download shows its progress; the list gives up after 5 minutes with a retry instead of loading forever.

### Achievements
- Everything RetroAchievements now lives in one place: Settings → Achievements (was split between Databases and the RetroArch page). Login and Web API key are two clearly labelled steps, with a button that opens the RA page where the key is.
- The Web API key is checked when you save it: a key RetroAchievements refuses is not stored. Without a login the key is still checked on its own.
- Live status: avatar, name, hardcore/softcore points and rank, a light each for login and key (with the error if one fails), time of the last successful check, and your latest unlocks with badges.
- Library match shows how many RA games and consoles were synced and how many of your library files have achievements.
- New in-game options for the managed RetroArch: unlock pop-ups, unlock sound, screenshot on unlock, leaderboard pop-ups, challenge indicators, badges in RetroArch's menu, encore mode. Untouched options keep RetroArch's default.

### Appearance
- New Omarchy theme: the Matte Black palette, monospace everywhere, flat square panels with a border that lights up like a focused Hyprland window. System → Appearance or `Ctrl K` → "Theme: Omarchy".

### Import
- Far fewer to-dos after an import (strict 1G1R, three switches on the Rules page, all on by default; every move names its reason):
  - Ties are decided without asking: the original before a crack `[cr]`, before trainers `[t]` and other flags; no country tag or `(World)` before a country; fewer tags; then name order. A release you preferred still wins.
  - Releases 1G1R did not pick – duplicates, other regions, older revisions, tie losers – go to `_trash` (undoable) instead of the decision queue. Releases you marked "keep" are placed; games where every release is excluded and name-only matches still ask.
  - Arcade conflicts (same target, different content): both copies are checked against the core's DAT and the more complete one stays – a better inbox copy replaces the library copy, which goes to `_trash`; equally complete keeps the library copy. Without a DAT (e.g. Flycast's `_bios/dc`), a copy that holds every file of the other plus more wins; truly different copies still ask.
- After a database update, a clean library stays clean: discs recognized only by serial or game ID (Saturn, GameCube, Wii …) keep their names as long as the database names the same game, instead of being renamed to a guessed pressing, revision or region. Library files named exactly like one of two equal database entries no longer ask which one they are.
- Ambiguous matches pick the candidate the file's extension or folder points to.
- Planning over network shares (CIFS/SMB) is faster: no per-archive zip reads or folder checks (real library: ~25 s → ~10 s).

### Library
- Release year, studio and publisher columns in the library list (sortable; games without a year sort last), also shown in the game details.

### Dashboard
- Loading hint and progress bar while the library loads.

### Fixes
- Box art and screenshots fall back to the libretro-thumbnails GitHub mirror when the thumbnail server fails; misses are retried after a week instead of never.
- Import no longer stops midway when a duplicate game folder goes to `_trash`: its frontend files (gamelists, readmes) already headed for the frontend trash are no longer moved twice.
- RetroArch fullscreen on Hyprland with a fractionally scaled monitor: the picture no longer starts oversized and off-centre (the app re-toggles fullscreen once after start).
- Omarchy theme: the edge between sidebar and content is a plain line again (the app's WebKit kept the neon gradient, which showed as a red fade).
- A 1G1R tie you resolved ("prefer") no longer comes back on every plan: the stored choice was read back as "discard".
- Linux with NVIDIA: the window no longer stays black. WebKitGTK's DMA-BUF renderer is turned off only when the NVIDIA driver is loaded (unless `WEBKIT_DISABLE_DMABUF_RENDERER` is set), so AMD and Intel keep GPU rendering and a responsive UI.
- Resolving an ambiguous zip stores the ROM's hash, not the archive's, so the decision no longer comes back on every plan.
- Launchers next to a game found in a subfolder count as that game's data.
- Game folders without a database match list as one game, not as unknown files.
- Unknown files show their file name and sort last.
- RetroArch page: without an installation, only the install button shows (no "Update to" or "Check for updates"), together with the nightly option.

- Local Arch Linux package (`packaging/arch/PKGBUILD`) with desktop entry and icons.
